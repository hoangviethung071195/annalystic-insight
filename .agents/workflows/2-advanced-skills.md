# Sprint 2: Nâng cao (Tuần 4-6)

Mục tiêu: Xây dựng các kỹ năng chuyên sâu cho từng phòng ban và thiết lập hệ thống phân quyền.

## 1. Role-Based Skills Development
- **Kế toán**: Kỹ năng tổng hợp dòng tiền, cảnh báo công nợ.
- **Marketing**: Kỹ năng phân tích ROI, gợi ý content.
- **Sale**: Kỹ năng báo giá tự động, kiểm tra tồn kho.

## 2. System Prompt Engineering
- Thiết kế System Prompts riêng biệt cho từng phòng ban.
- Tích hợp logic xử lý số liệu (GPT-4o) và phân tích sáng tạo (Claude 3.5).

## 3. RBAC (Role-Based Access Control)
- Thiết lập cơ chế kiểm tra quyền truy cập Sheet trong n8n.
- Tích hợp yêu cầu mã OTP cho các truy vấn dữ liệu nhạy cảm (tài chính).

## 4. Skills Testing
- Kiểm thử độ chính xác của AI khi đọc hiểu dữ liệu số.
- Đảm bảo AI không truy cập trái phép dữ liệu ngoài phạm vi quyền hạn.
